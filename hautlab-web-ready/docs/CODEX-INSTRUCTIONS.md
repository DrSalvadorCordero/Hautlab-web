# Instrucciones para Codex

Trabaja como desarrollador senior de una marca médica premium.

## Objetivo

Construir y mantener una web sobria, rápida, elegante y orientada a conversión para Dr. Salvador Cordero.

## Prioridades

1. Performance.
2. Mobile-first.
3. SEO local.
4. Conversión a WhatsApp.
5. Tracking limpio para Meta Ads y Google Ads.
6. Diseño editorial premium.
7. Cumplimiento básico para comunicación médica.

## No hacer

- No inventar datos médicos.
- No hacer claims de resultados garantizados.
- No usar tono de spa.
- No saturar la interfaz.
- No agregar animaciones innecesarias.
- No agregar dependencias sin justificación.
- No modificar branding sin permiso.
- No colocar claves privadas en frontend.

## Antes de entregar

- Revisar errores de TypeScript.
- Revisar responsive mobile.
- Confirmar que los CTAs funcionan.
- Confirmar que no hay claves privadas expuestas.
- Explicar cambios en lenguaje claro.

## Formato ideal de respuesta de Codex

1. Qué cambió.
2. Archivos modificados.
3. Cómo probar.
4. Riesgos o pendientes.
