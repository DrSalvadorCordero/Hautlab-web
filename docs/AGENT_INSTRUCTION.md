# Agent Instruction

Audit and improve HAUTLAB using the governance documents in this directory.

Before changing code or content:

- Read all governance files.
- Confirm the repository architecture.
- Verify facts from trusted source data.
- Separate Mérida and CDMX.
- Identify the smallest high-impact change.

Work only on a dedicated branch. Run available checks. Open a draft pull request. Do not merge, deploy or alter medical, regulatory, pricing, credential or location facts without explicit approval.
