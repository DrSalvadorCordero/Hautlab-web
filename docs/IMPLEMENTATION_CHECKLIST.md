# HAUTLAB Implementation Checklist

Before opening any SEO/AEO pull request, verify:

- The change follows all files in `/docs`.
- The page has one clear primary intent.
- Mérida and CDMX data are not mixed.
- Claims, prices, locations and credentials are sourced.
- Metadata and canonical URLs are correct.
- Schema matches visible content.
- Internal links are contextual.
- Mobile and accessibility behavior remain intact.
- Available build, lint and type checks pass.
- The pull request lists expected impact and unresolved risks.

Before merge, obtain explicit approval for any change involving medical advice, credentials, pricing, sponsorship, locations, schedules, patient data or regulatory-sensitive copy.
